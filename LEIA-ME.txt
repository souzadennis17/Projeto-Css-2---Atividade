NARUTO SHIPPUDEN — Projeto HTML + CSS básico

Arquivos:
- index.html: página inicial
- personagens.html: personagens
- vilas.html: vilas ninja
- jutsus.html: técnicas ninja
- organizacoes.html: organizações
- historia.html: história de Naruto
- css/index.css: estilos da página inicial
- css/personagens.css: estilos da página de personagens
- css/vilas.css: estilos da página de vilas ninja
- css/jutsus.css: estilos da página de jutsus
- css/organizacoes.css: estilos da página de organizações
- css/historia.css: estilos da página de história

Como abrir:
1. Extraia todos os arquivos para a mesma pasta.
2. Abra index.html no navegador.
3. Use os menus para navegar entre as seis páginas.

Cada página HTML possui seu próprio arquivo CSS externo. Os estilos usam
propriedades abordadas em aula, incluindo line-height: 30px, text-transform
(uppercase, lowercase, capitalize e none) e a forma abreviada font.
A tag meta viewport está presente em todas as páginas.
